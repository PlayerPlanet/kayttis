# Loppudemon tarkistuslista (v2)

Vastuuhenkilöt merkitään hakasulkeisiin. Rasti ruutuun, kun valmis.

Kaava: **väite** (Tavallinen hana. Hanax tietää, onko se auki.), **todiste** (prototyyppi killan keittiössä livenä), **toiminto** (Katso livenä). Rehellisyys: renderöinnit = *konseptimalli*, AI Studion kuvat = *konseptikuva*, hinta = *tavoite*, pilvettömyys ja Suomi-säilytys = *tavoite*, sammutus sovelluksesta = *simuloitu*.

## Viikkoa ennen

- [ ] Roolijako sovittu: kuka puhuu missäkin diassa (`[Puhuja 1–4]`, ks. `pitch.md`) [ ]
- [ ] Esitys harjoiteltu kellon kanssa vähintään kahdesti, kesto 4–5 min [ ]
- [ ] Jokainen osaa 30 s hissipuheen ja 2 min ständipuheen [ ]
- [ ] Kysymyksiin vastaaminen käyty läpi (ks. `pitch.md` osio 4), erityisesti HX-01-konsepti, ESP32-CAM, kameran yksityisyys ja "miksi kamera" [ ]
- [ ] Samanväriset asut sovittu (grafiitti tai musta, v2-brändin mukaan) [ ]
- [ ] Sähköpostikutsu lähetetty testaajille ja ystäville (`sahkoposti.md`) [ ]
- [ ] Some-julkaisut ajastettu (`some.md`) [ ]

## Perjantai: laitteisto ja kuvat

- [ ] ESP32-CAM-moduuli ja raakakomponentit (akku, magneetti, USB-C, johdot) esillä tummalla alustalla konseptirenderöintien vieressä [ ]
- [ ] Renderöinnit tulostettu tai näytöllä, jokaisessa merkintä "Konseptimalli" (`brand/renders/`) [ ]
- [ ] Pieni kyltti rautaan: "Tästä HX-01 rakentuisi · ESP32-CAM · 27 × 40,5 mm" [ ]
- [ ] Todistekuvat kuvattu itse, ei tekoälyllä (ks. `launch/ai-studio/PROMPTS.md`):
  - [ ] P1 · Oikea venttiili punaisella teipillä: käsi kääntää auki ja kiinni, kumpikin tila 3 s [ ]
  - [ ] P2 · Live-sovelluksen ruutunauhoite samaan aikaan kuin P1, kello näkyvissä [ ]
  - [ ] P3 · ESP32-CAM ja komponentit tummalla pöydällä, yksi sivuvalo; hidas lähestyminen ja ylhäältä still [ ]
  - [ ] P4 · ESP32-CAM suunnattuna venttiiliin siihen kohtaan, jossa HX-01 olisi [ ]
  - [ ] P5 · Älypistorasia kahvinkeittimessä: keitin käynnistyy ja sovelluksen tehonlukema muuttuu [ ]
- [ ] AI Studion konseptikuvat (S1–S7, V1–V4) valittu, ja jokaisessa näkyy merkintä "konseptikuva" [ ]
- [ ] Tarkistettu, ettei yhtään AI-kuvaa tai renderöintiä esitetä todisteena [ ]

- [ ] kayttis.kiirikki.fi/app aukeaa ständin laitteilla [ ]
