# Loppudemon tarkistuslista

Vastuuhenkilöt merkitään hakasulkeisiin. Rasti ruutuun, kun valmis.

## Viikkoa ennen

- [ ] Roolijako sovittu: kuka puhuu missäkin diassa (`[Puhuja 1–4]`, ks. `pitch.md`) [ ]
- [ ] Esitys harjoiteltu kellon kanssa vähintään kahdesti, kesto 4–5 min [ ]
- [ ] Jokainen osaa 30 s hissipuheen ja 2 min ständipuheen [ ]
- [ ] Kysymyksiin vastaaminen käyty läpi (ks. `pitch.md` osio 4), jokaisella oma vastuualue [ ]
- [ ] Samanväriset asut sovittu (esim. yönsininen tai oranssi brändiväri) ja hankittu [ ]
- [ ] Sähköpostikutsu lähetetty testaajille ja ystäville (`sahkoposti.md`) [ ]
- [ ] Some-julkaisut ajastettu (`some.md`) [ ]

## Painotuotteet

- [ ] Julisteet tulostettu ja tarkistettu: ongelma, ratkaisu, käyttäjäryhmä, arvolupaus näkyvät [ ]
- [ ] One-pager tulostettu, riittävästi kappaleita jaettavaksi [ ]
- [ ] Kiinnitystarvikkeet: sinitarra, teippi, telineet [ ]

## Video

- [ ] Esittelyvideo pyörii silmukassa ständin näytöllä, ääni sopivalla tasolla tai tekstitettynä [ ]
- [ ] Varmuuskopio videosta paikallisena tiedostona USB-tikulla ja läppärillä (ei verkon varassa) [ ]
- [ ] Testattu, että video käynnistyy offline-tilassa [ ]

## Prototyyppi ja demo

- [ ] Raspberry Pi päällä ja verkossa killan keittiössä; `/api/health` näyttää lähteet kunnossa [ ]
- [ ] Kamera osoittaa astianpesukoneen hanaan, rajaus kunnossa; hanaluokittelija näyttää oikean tilan [ ]
- [ ] Kahvinkeittimien pistorasiat ja valot näkyvät sovelluksessa livenä [ ]
- [ ] kayttis.kiirikki.fi/app aukeaa ständin laitteilla [ ]
- [ ] Demotunnukset valmiina ja kirjattu paperille ständille (ei julkisesti näkyviin) [ ]
- [ ] Ständin puhelimet ja tabletit ladattu, sovellus valmiiksi auki ja kirjautuneena [ ]
- [ ] Demokäsikirjoitus harjoiteltu: näytä live-tila, tuoreusleima, sammuta laite, "kaikki pois" [ ]
- [ ] Varasuunnitelma, jos live-data katkeaa: sovellus toimii ilman API:a ("Live data offline"), kerro se ääneen ja näytä simuloitu tila [ ]
- [ ] Muista sanoa demossa: lukemat ovat oikeita, sammutus on simuloitu [ ]
- [ ] Laturit, jatkojohto, HDMI-adapteri [ ]

## Esitys

- [ ] Diat auki ja testattu esityslaitteella, varalla PDF-vienti [ ]
- [ ] Puhujien järjestys ja siirtymät sovittu [ ]
- [ ] Ajanottaja ryhmästä [ ]

## Ständillä

- [ ] Sisäänheittäjä: yksi henkilö kutsuu ohikulkijoita kysymyksellä "Muistatko, sammutitko lieden?" [ ]
- [ ] Yksi esittelee demoa, yksi vastaa kysymyksiin, yksi pitää videon ja materiaalit kunnossa [ ]
- [ ] Ota kuvia ja kirjaa ylös kävijöiden kysymykset jatkokehitystä varten [ ]

## Lopuksi

- [ ] Kiitosviesti testaajille demon jälkeen [ ]
- [ ] Pi jätetään päälle tai sammutetaan hallitusti sovitusti [ ]
